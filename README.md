# testproject

A snake game that runs in your terminal.

## Run it

```sh
uv run testproject
```

(Works from the project root or any subdirectory — uv discovers the project
by walking up from the current directory.)

## Controls

| Key | Action   |
| --- | -------- |
| `h` | left     |
| `j` | down     |
| `k` | up       |
| `l` | right    |
| `q` | quit     |
| `r` | restart after game over |

Arrow keys also work. Eat the `*` to grow and score points — don't hit the
walls or yourself. The snake speeds up as you eat.
